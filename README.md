# University-Game-Project
University coursework PC game developed in Unity with C#. A top down survival shooter focused on a 60 second challenge, featuring melee and ranged enemies, player health and scoring systems with temporary and permanent upgrades.

# Top-Down Survival Shooter
University coursework project for the Games Computing Degree

## About the Project
This is a first year PC game project development as part of my Games Computing course
The game is a top down survivals hooter where the player must survive for 60 seconds against enemies with both melee and ranged attacks.

## Gameplay Features
- Top Down Shooter Gameplay
- 60 Second survival objective
- Melee and ranged enemy types
- Player Health System
- Score tracking system
- Temporary and permanent gameplay upgrades that support player progression

## Technologies used
- C#
- Unity

## Current Status
Unfinished.

## What I learned
- Implementing gameplay mechanics in C#
- Enemy Behaviour design (mele and ranged)
- Debugging and testing gameplay systems
- Iterative development and balancing
